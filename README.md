# worklyApp

Минималистичное TUI приложение для продуктивности на Go.

## 📋 Возможности

- 🌤️ Погода (OpenWeatherMap API)
- 📝 Заметки с тегами
- ✅ TODO листы с приоритетами
- 🚗 Пробки в городе
- 🎨 Красивый TUI интерфейс

## 🚀 Установка

```bash
git clone https://github.com/ваш-ник/productivity-tui.git
cd productivity-tui
go run main.go
